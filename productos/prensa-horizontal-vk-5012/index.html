Descripción

Para las empresas profesionales de eliminación de residuos o aplicaciones industriales de tipo mediano – altos rendimientos de paso hasta aprox. 442 m³/h

Características

  • Suelo de la cámara, canal de prensado y lados en Acero resistente al desgaste
  • El software ajustado de forma óptima para los distintos tipos de materiales garantiza una elevada calidad de las balas, incluso con un cambio frecuente del material
  • Apertura de llenado de grandes dimensiones para materiales voluminosos
  • Solución polivalente para materiales con una densidad de carga de hasta 60 kg / m³
  • Disponible opcionalmente para materiales de residuo (acero resistente al desgaste)
  • Control del proceso de prensado mediante célula fotoeléctrica. Apropiada para una carga de forma continua con cinta de transporte, alimentación por aire o similar
  • Dimensiones y pesos de las balas optimizados para una descarga rentable del camión
  • Especialmente adecuado para cartón, papel y plástico, pero también para comprimir materiales DSD y botellas PET (otros materiales bajo consulta)
  • Atadura quíntuple totalmente automática para un resultado óptimo en el caso de materiales expansivos
